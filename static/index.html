                    About
                    
        
                    Forge Studio
                    A desktop studio for AI coding agents — chat, live preview, and Android build & debug tools. Runs locally on this computer.
                    
        
                    What agents can make
                    
        
                    Agents can write code, documents (Markdown, HTML, PDF/DOCX via scripts), spreadsheets, diagrams and SVG graphics, and anything a script can produce. Files they create show up with Open / Download buttons in the chat. Claude models don't generate photos or videos themselves; for that, add a CLI or script that calls an image/video API.
