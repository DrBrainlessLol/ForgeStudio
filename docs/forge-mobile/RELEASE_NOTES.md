# Forge Mobile release notes

## 0.3.0

The Android companion for Forge Studio: chat with your agents, watch their thinking and commands live, approve or deny actions, browse and edit files, review Git changes, build and run Android apps, open a terminal, and lock the computer, from anywhere through a Cloudflare Tunnel or on your home network.

**Download:** [`ForgeMobile-0.3.0.apk`](https://github.com/DrBrainlessLol/ForgeStudio/releases/download/mobile-v0.3.0/ForgeMobile-0.3.0.apk). Android 8.0 or newer.

### Install
1. Download the APK on your phone and open it. Android asks to allow installs from your browser or file manager; allow it for this install.
2. In Forge Studio on your computer, open **Settings → Web App → Phone app & Cloudflare Tunnel** and scan the QR code with the app. See [Remote access from your phone](https://github.com/DrBrainlessLol/ForgeStudio/blob/main/README.md#remote-access-from-your-phone).
3. Requires Forge Studio 1.3.1 or newer. Terminal, unlock, adb control and localhost preview stay off until you switch them on in Forge Studio ([Security switches](https://github.com/DrBrainlessLol/ForgeStudio/blob/main/README.md#security-switches)).

### Highlights
- Live chat with expandable thinking and tool steps, approval cards, voice typing, attachments (including zip and APK files), drafts and message actions.
- File browser and editor, Chat files, Git changes and diffs, web preview of your dev server.
- Android tools: build, quick Gradle tasks, built APKs you can install on the phone, emulators, device screen and filtered logcat.
- Terminal, lock and unlock the computer, emergency recovery PIN, wireless adb manager.
- Notifications (battery saver by default), light/dark/system themes, accent colors, your own API-key providers.
- Optimised build for smoother scrolling and a smaller install.

### Notes
- This build is signed with a personal development key, so it is meant for sideloading and will not update an app installed from a different source.
